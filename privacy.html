Privacy policy

Health Coach · effective 5 October 2026 · Home

Who uses this app

Health Coach is a personal app used only by its owner, the owner of this GitHub account. Its web app is restricted to the owner's Google account, and no one else is given access.

What data it reads

With the owner's permission, Health Coach reads the following through the Google Health API. Access is read-only, so it never changes or deletes anything in Google Health.

  • Activity and fitness data, such as steps, active zone minutes and exercise sessions
  • Health metrics and measurements, such as heart rate, heart rate variability, oxygen saturation, breathing rate, skin temperature and weight
  • Sleep data, such as sleep sessions and sleep stages
  • Irregular rhythm notifications

How the data is used

The data is used only to calculate and show the owner's own dashboard metrics, trends and coaching notes. If the owner turns them on, the app also sends alert emails to the owner's own address.

Where the data is stored

All data stays inside the owner's Google account. It is stored in a folder that the app creates in the owner's Google Drive, plus the script's private settings. The app has no server or database of its own.

Sharing

The data is not sold, rented or shared, and it is not used for advertising. There is one optional feature, off by default. If the owner turns on a daily review, Anthropic's Claude reads a de-identified summary file in the owner's Drive at the owner's request and writes a coaching note back to the same folder. The summary contains no name or email address.

Google API Services User Data Policy

Health Coach's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

Data is kept until the owner deletes the Health Coach folder in Google Drive or the Apps Script project. To stop all access, remove Health Coach at myaccount.google.com/permissions.

Changes and contact

Any change to this policy will be posted on this page with a new effective date. For questions, open an issue in this repository.
